AI-assisted animation systems can generate and refine motion, but conversational performance also depends on interpretable acting decisions. We present a context-aware authoring workflow that exposes these decisions as editable \textit{Semantic Performance Tags} between narrative interpretation and deterministic animation execution. For dyadic dialogue, a pretrained LLM proposes shared initial states and sparse dialogue-anchored performance beats that animators can revise in Maya before compilation to JALI controls. We evaluate the workflow with 16 participants. Editable tags significantly increased match to intended reading and final satisfaction after Holm correction, while no workflow-item or NASA-TLX difference survived correction. In a text-only context ablation, Full-Context proposals significantly improved overall scene fit (Holm-adjusted $p=.025$), while intention, affect, gaze, and timing did not. Fixed workflow order and incomplete interaction logging limit causal and accept/modify/reject claims.
