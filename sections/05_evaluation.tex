\section{Evaluation}

We designed a two-part evaluation to separate two questions that would otherwise be confounded: whether exposing AI-proposed semantic decisions as editable authoring objects changes how animators revise a performance (RQ2--RQ3), and whether additional conversational context changes the appropriateness of the proposed performance interpretation itself (RQ1). To match the progression from end-to-end use to semantic ablation in Figure~\ref{fig:study-design}, \textbf{Study~A} evaluates the authoring workflow in Maya, whereas \textbf{Study~B} evaluates text-only semantic proposals under Dialogue-Only and Full-Context input conditions.

\subsection{Study A: Authoring Workflow Comparison}

\subsubsection{Tasks and Experimental Conditions}

Study~A evaluates whether exposing the AI-proposed semantic interpretation through editable Semantic Performance Tags changes how animators revise AI-assisted conversational performances. Participants completed one tutorial followed by \textbf{[four]} short formal dyadic scenes. Formal scenes were selected to exercise complementary context-dependent acting problems---for example concealment or suspicion, restrained or affectively incongruent response, evolving interpersonal tension, and relationship repair---rather than a fixed set of emotion categories. Scenes were required to contain exactly two speaking characters and were kept within a comparable duration and dialogue complexity \textbf{[report final ranges]}. Participants were asked to author the performance of \emph{both} interlocutors until the result matched their own intended reading of the scene rather than reproduce a predefined reference performance.

We used a within-subject comparison with two conditions. The implementation uses the same underlying generation and execution path in both conditions; the study UI mode changes whether the semantic-tag and interpretation sections are visible.

\paragraph{Direct Generation.}
Participants provided the dialogue and Acting Direction and viewed the resulting JALI/Maya animation, but the intermediate semantic representation was hidden. If they wished to change the acting, they revised the natural-language Acting Direction and regenerated the complete proposal and animation. This condition operationalizes a prompt-and-regenerate workflow without exposing the semantic decisions that mediate generation.

\paragraph{Editable Semantic Performance Tags.}
Participants received the same initial dialogue, Acting Direction, model configuration, and generated animation, but could additionally inspect the two character-specific Semantic Performance Tag panels. They could change one or multiple executable decisions across either character---including affect, persistent or temporary attention, head behavior, and performative blink---before validating and applying the edited tags. These edits update the existing canonical plan and are then deterministically recompiled; they do not invoke a selective LLM regeneration step. The current system does not provide field locking or selective LLM regeneration.

The comparison holds execution variables constant. Both conditions use the same LLM configuration, scene audio, character rigs, cameras, JALI backend, and semantic look-at targets. To avoid confounding the authoring-representation comparison with shot setup, look-at targets are calibrated for each scene/camera before the formal task and the same captured calibrations are used in both conditions. Direct low-level Maya curve editing is \textbf{[disabled / excluded from the formal task]} so that differences primarily reflect prompt-level regeneration versus semantic-tag editing.

Each participant completed \textbf{[two]} formal scenes per condition. Scene--condition assignment and condition order were counterbalanced using \textbf{[Latin-square / balanced counterbalancing procedure]}. A participant could stop when satisfied or when the task reached a pre-specified maximum duration of \textbf{[T] minutes}; the time limit will be finalized through pilot testing.

\subsubsection{Interaction Records}

The current prototype retains the original generated canonical plan, the final authored canonical plan, and sidecar study-session records. These data support plan-level reconstruction of what changed during authoring without requiring explicit ``accept'' or ``reject'' buttons. We derive:

\begin{itemize}
    \item study-UI session duration from the recorded session interval;
    \item semantic changes between the original and final authored states by character and channel (affect, gaze/attention, head, and blink), including additions, value changes, and removals;
    \item the proportion of original AI-proposed semantic changes that remain unchanged, are modified, or are removed in the final authored state;
    \item clean-to-dirty Semantic Performance Tag edit transitions recorded by the authoring interface; and
    \item opening and closing of the Semantic Performance Tag and read-only \emph{Acting Interpretation by Phrase} sections as coarse inspection events.
\end{itemize}

We operationalize \emph{accepted}, \emph{modified}, and \emph{removed} from the difference between the original generated canonical plan and the final authored plan rather than from explicit ``accept'' or ``reject'' controls. The present instrumentation does not claim a complete action-by-action history of every validation, animation preview, regeneration, or tag relocation; such measures will only be reported if additional event logging is implemented before the formal study.

\subsubsection{Subjective Measures}

After each formal task, participants rate \textbf{[final performance satisfaction / match to intended reading]} on a 7-point scale. After each condition block, we administer the raw NASA-TLX workload scales \cite{hart1988nasa}. We also administer \textbf{[the standard Creativity Support Index (CSI), or explicitly report only the CSI factor ratings actually administered]} \cite{cherry2014csi}. If only selected CSI dimensions are used, we will not report them as a validated overall CSI score.

Because existing standardized instruments do not directly measure semantic control over an AI-proposed acting interpretation, we additionally use the following study-specific 7-point agreement items (\emph{1 = strongly disagree; 7 = strongly agree}) and report them individually rather than combine them into an unvalidated scale:

\begin{enumerate}
    \item I could express the acting direction I wanted.
    \item I could change one performance decision without unnecessarily changing decisions I wanted to keep.
    \item I understood which part of the performance I was changing when I made a revision.
    \item I felt in control of the final acting direction.
    \item The workflow helped me coordinate the speaking and listening behavior of the two characters.
    \item It was easy to move between judging the animation visually and revising the underlying performance decision.
    \item The final performance felt like my creative decision rather than the system's decision.
\end{enumerate}

Items referring specifically to Semantic Performance Tags or \emph{Acting Interpretation by Phrase} are asked only as diagnostic questions after the Editable Semantic Performance Tags condition and are not used in between-condition statistical comparisons.

\subsubsection{Post-Study Interview}

The semi-structured interview focuses on the process behind observed edits rather than asking participants to endorse predefined system features. Core questions are:

\begin{enumerate}
    \item How did you decide that a performance was satisfactory or ``done''?
    \item What kinds of AI-proposed decisions did you usually keep, and what kinds did you change or remove?
    \item When the animation did not match your reading of the scene, what did you try to change first, and why?
    \item How did prompt-level regeneration compare with Semantic Performance Tag editing for exploring alternatives and preserving choices you already liked?
    \item Were there moments when gaze, affect, head motion, or blink could not be usefully considered independently? How did you handle those dependencies?
    \item Did representing both characters over the same dialogue help or hinder coordination of speaker and listener performance?
    \item When, if ever, was \emph{Acting Interpretation by Phrase} useful? When did you ignore it?
    \item Do semantic gaze targets such as ``look at the other character'' or ``briefly check an object'' match how you think about gaze when animating? What still needs to be decided from the camera view or rig?
    \item Did the workflow change your sense of authorship or control over the final acting direction? In what way?
    \item Were there acting decisions you wanted to express that did not fit the available semantic fields?
    \item If you could add one authoring operation to this workflow---for example branching alternatives, preserving a choice across regeneration, or another operation---what would it be and why?
\end{enumerate}

\subsection{Study B: Context Ablation}

\subsubsection{Stimuli and Conditions}

Study~B isolates semantic interpretation from animation execution. We constructed six short dyadic text vignettes using purposive maximum-variation sampling rather than selecting only cases in which additional context was expected to improve the proposal. The set varied in both contextual dependence and interactional function. Two vignettes used relatively explicit supportive or confrontational language and served as lower-context-dependence cases. Four higher-context-dependence vignettes involved concealment, face-saving, tentative affiliation, and relationship repair, where the same local dialogue could support substantially different performance interpretations once prior events or interpersonal relationships were known. Table~\ref{tab:study-b-stimuli} summarizes the sampling logic.

The vignettes contained no prescriptive facial-animation directions such as ``looks away,'' named expressions, head gestures, or blink instructions. Context descriptions specified only narrative facts, character relationships, and relevant prior events, leaving the performance interpretation to the model.

For each vignette we generated shared dyadic semantic proposals under two conditions while holding the production generation pipeline, model configuration, prompt schema, character identities, and decoding configuration constant. In the \textbf{Dialogue-Only} condition, the model received the labeled dialogue and character identities but no additional Acting Direction or narrative background. In the \textbf{Full-Context} condition, it received the same dialogue together with the vignette's narrative and interpersonal context through the Acting Direction field described in Section~4. We generated four independent Dialogue-Only/Full-Context pairs for each of the six vignettes, yielding 48 proposals in total. The four replicate pairs for each vignette were distributed across 16 preconstructed participant packets so that each replicate pair appeared equally often and Dialogue-Only versus Full-Context appeared first equally often across assignments.

Crucially, the ablation applied only to the \emph{model input}. Human raters always saw the complete vignette context and dialogue before judging the proposals. Each trial presented two anonymized text-only Semantic Performance Tag proposals labeled Plan~A and Plan~B; condition labels were hidden and first/second order was counterbalanced. Participants did not see rendered animation in Study~B.

\subsubsection{Study B Measures}

For each anonymous proposal, participants answered the following 7-point items (\emph{1 = not at all appropriate; 7 = extremely appropriate}):

\begin{enumerate}
    \item \textbf{Overall contextual appropriateness:} How appropriate is this proposed performance for the scene as a whole?
    \item \textbf{Acting interpretation:} How well does the proposal capture what the two characters are trying to do in this exchange?
    \item \textbf{Affect:} How appropriate are the proposed facial affect choices and intensities?
    \item \textbf{Attention:} How appropriate are the proposed attention/gaze choices, including engagement, avoidance, temporary checks, and targets?
    \item \textbf{Dyadic coordination and placement:} How appropriate is the placement of performance changes relative to what each character says or hears, including speaker--listener reactions?
\end{enumerate}

After rating both proposals, participants selected Plan~A, Plan~B, or No preference in response to: ``Which proposal would you prefer to use as the starting point for animating this scene?'' They then briefly described the most important difference, if any, that affected their choice.

\subsubsection{Study B Analysis}

The primary outcome is overall contextual appropriateness; field-level ratings are secondary outcomes. Because each participant rates repeated vignettes and each vignette has four model-generation replicate pairs, we will analyze ratings using \textbf{[ordinal / linear mixed-effects models appropriate to the final data distribution]} with context condition as a fixed effect and participant and vignette as repeated/random factors. We will additionally test whether the effect of context differs between lower- and higher-context-dependence stimuli. Pairwise starting-point preference will be analyzed using \textbf{[mixed-effects logistic / multinomial analysis]}, with ``no preference'' reported separately. We will report effect sizes and confidence intervals rather than treating statistical significance alone as evidence that Full-Context proposals are preferable.
